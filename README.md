# ExpenseKeeper

A small native Android expense tracker focused only on expenses.

- Persian and English UI
- First-run setup for language, theme, and Jalali period start day
- Current-period dashboard with category chart
- Editable colorful categories and subcategories
- SMS import into uncategorized expenses
- Expense splitting across multiple categories
- Daily, weekly, and period home-screen widget

Build requirements:

- Android Gradle Plugin 8.5.2
- Gradle 8.7
- `minSdk 23`
- `compileSdk 34`

The Gradle repositories include:

```groovy
maven {
    url 'https://maven.myket.ir'
}
```
